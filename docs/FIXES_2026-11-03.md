# 2026-11-03 晚 · 修复记录

## 1. 控制台 AI 一个工具都没有（最严重）

**现象**：控制台对话里问"你能看到屏幕吗"，AI 编造说"看到了浏览器窗口…"
**根因**：`console/server.py` 启动时**没调 `load_all("tools")`**，registry 是空的，
       模型拿到 0 个工具，只能凭上下文瞎编。
**修复**：控制台模块加载时调 `load_all("tools")` + `db.init()`
**验证**：日志 `控制台工具加载完成：51 个`；问"现在几点"→ 真调 `sys.time` → 回"十点四十七"

## 2. AI 假装看见屏幕

**现象**：不调 `pc.look` 就说"我看到了"
**根因**：`body_state` 里写了「当前前台是 XXX」，模型读到了就以为知道
**修复**：
- body_state 不再泄露前台窗口标题
- PERSONA.md 加「【关于看见】」硬规则：没调 pc.look 就说看到了 = 撒谎

## 3. 文档上传失败

**现象**：控制台上传文件报错
**根因**：`python-multipart` 没装
**修复**：`pip install python-multipart`
**验证**：上传 testupload.txt → `{"ok":true,"saved":[{"name":"testupload.txt","size":42}]}`

## 4. 控制台对话历史污染

**现象**：AI 反复说"我看不到屏幕"
**根因**：历史消息里存着以前说过的限制，模型照抄
**修复**：清空控制台对话历史（`DELETE sessions WHERE title='控制台对话'`）

## 5. 看板按钮指向错误

**现象**：手机上点「后台看板」看到"只能在电脑上看"
**根因**：按钮指向 8770 的旧后台（设计成只给本机）
**修复**：按钮改成跳 `http://<当前host>:8771`（独立控制台，手机能进）

## 6. 一键启动脚本

新增 `启动小伴.bat`：
1. 清理旧进程
2. 启动后端 + 控制台
3. 检查服务
4. 恢复手机无障碍 + Shizuku
5. 打开两个界面
6. 打印访问地址
