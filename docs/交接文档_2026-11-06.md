## 七、重要的坑（血泪教训）

### 7.1 E 盘不能放数据库 ⚠️

```
E: 是 exFAT，断电/异常拔出会坏目录索引
2026-11-04 因此丢了 data 目录（数据救回来了，但折腾半天）
→ 数据一律放 D:\xiaoban-data（NTFS）
→ E 盘建议跑一次 chkdsk /f（还没跑）
```

### 7.2 动 Program Files 前必须备份 ⚠️

```
2026-11-04 我为了装 NapCat，删了 QQ 的
resources\app\package.json，导致 QQ 报"文件已损坏"，
用户只能重装 QQ。

现在有防护：
· tools/_protect.py —— 系统目录写入/删除会被拦
· 必须传 allow_system=true 才放行，且自动备份
· PERSONA.md 里写了硬规则
```

### 7.3 手机 App 重装必掉无障碍 ⚠️

```
每次 adb install -r 之后，无障碍服务都会掉。
解决：Keeper.java 会自动恢复（30 秒检查一次）
或者手动：
  adb shell settings put secure enabled_accessibility_services com.xiaoban.app/com.xiaoban.app.XiaobanAccessibilityService
  adb shell settings put secure accessibility_enabled 1
```

### 7.4 虚拟屏在这台手机上不可能 ⚠️

```
vivo V2445A（iQOO Z9 Turbo）封了 DisplayManager.createVirtualDisplay
用 headless-android（成熟项目）对照测试，同样失败
→ 别再尝试，浪费时间
```

### 7.5 控制台 AI 曾经没加载工具

```
console/server.py 启动时必须调 load_all("tools")，
否则控制台的 AI 一个工具都没有，只会瞎编。
（已修，但改代码时注意别删掉）
```

### 7.6 写文件工具在 E 盘会报 EISDIR

```
E:\WH 是 exFAT，某些 write 操作会失败
→ 一律用 win_bash 的 heredoc 写文件
```

### 7.7 手机 QQ 聊天窗口读不到

```
QQ 主界面（聊天列表）无障碍可读 ✅
QQ 聊天窗口是 Canvas 渲染，读不到内容 ❌
微信整个界面都屏蔽无障碍 ❌
```
