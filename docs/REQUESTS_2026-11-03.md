# 小伴提出的需求 · 落实情况（2026-11-03）

> 小伴（AI 端）提出，阿伟转达，后端落地。

## 一、自我更新 ✅
**需求**：能读取并修改自己这一端的代码/配置，用户提优化需求时直接落地。

**落地**：新增工具 `pc.self_update`
- `action=list` 列出可编辑文件
- `action=read` 读源码
- `action=write` 整篇覆盖（自动备份 + Python 语法校验 + 出错自动回滚）
- `action=patch` 查找替换（比整篇覆盖安全）

**安全底线**：
- 只能动 `E:\WH\pc-core`，不能碰 `data/ .git/ .venv/ logs/ workspace/ plugins/`
- 每次写先存 `<文件>.bak-<时间戳>`
- Python 文件写完立刻 `py_compile`，不通过自动还原
- 底线文件（reviewer.py / auth.py / 本工具自己）必须 `confirm=true`

## 二、主动说话 ✅
**需求**：不能只被动等用户开口，要有主动触发通道（定时提醒、资源告急）。

**落地**：
- `core/proactive.py` 主动消息队列（SQLite，离线不丢）
- API：`/api/proactive/pending` `/api/proactive/ack` `/api/proactive/push` `/api/proactive/state`
- 前端每 20 秒拉一次，显示成带青色左边条的气泡
- 自动触发：
  - autopilot 定时行为 → 自动转成主动消息
  - `check_resources()` 内存/CPU/磁盘告急 → 主动提醒（带 30-60 分钟冷却，不刷屏）

## 三、记忆增强 ✅
**需求**：自动沉淀 / 按时间和场景检索 / 能更新能遗忘。

**落地**：
- **自动沉淀**：brain 每轮结束自动抽取（`_remember_turn`），不用显式调用
- **按时间检索**：`mem.recall` 支持 `since` / `until`，认「3天前」「上周」「昨天」「2026-10-01」
- **按场景检索**：支持 `category` 过滤（偏好/工作/家人/通用…）
- **更新**：`mem.update action=update`
- **遗忘**：`mem.update action=forget`（真删）/ `action=decay`（久未想起的降权，不硬删）
- 统一了两套存储：`mem.remember` 同时写 KV 表和分层记忆库，`mem.recall` 优先分层库

## 四、跨端联动 ✅
**需求**：能看到 PC 上的具体上下文；设备能和场景联动。

**落地**：
- `pc.context`：焦点窗口 + 开着哪些程序 + 多久没动鼠标键盘，输出人话
  例：「现在焦点在「DeepSeek Harness」；你已经 1 分钟没动了；开着：设置（2）、Notepad…」
- `device.scene`：一键场景
  - `sleep` 睡觉 → 关灯关电视关风扇
  - `leave` 出门 → 全关
  - `home` 回家 → 开灯开风扇
  - `work` 工作 → 灯 80、关电视、开风扇
  - 认自然语言：「我要睡了」「我回来了」

## 五、工具小诉求 ✅
**需求**：截图后能直接看到画面；只读命令白名单放宽。

**落地**：
- `pc.look`：截屏 → base64 → 视觉模型 → 返回画面描述（实测 11.6 秒看懂整个屏幕）
  - 配置在 `config.json` 的 `vision.model`，默认 `auto/deepseek-v4.1-flash`
- shell 白名单 15 条 → **75 条**（文件查看、系统信息、网络、开发工具、硬件）
- **支持管道**：`netstat -an | findstr :8770` 这种，要求每段都是白名单只读命令，最多 3 段
