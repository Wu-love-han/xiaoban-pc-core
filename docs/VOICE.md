# 语音模式

## 能力

| 能力 | 实现 | 状态 |
|---|---|---|
| 说话（TTS） | Windows SAPI，中文 Microsoft Huihui | ✅ 可用 |
| 听（STT） | Windows 语音识别，MS-2052-80-DESK (zh-CN) | ✅ 可用 |

## 工具

```
pc.speak       说话（rate 语速 -10~10，volume 0~100，async 不阻塞）
pc.listen      听一句话转文字（seconds 默认 5）
voice.mode     action=listen/speak/config 三合一
```

## API

```
GET  /api/voice/config    检查语音能力
POST /api/voice/speak     {text, rate, volume}
POST /api/voice/listen    {seconds}
```

## 界面

- 输入框旁边有个 **🎤 按钮**，点一下录 5 秒，识别结果自动填进输入框
- 设置里有「**回复时念出来**」开关，开了之后每轮回复自动播报

## 主动说话（重点）

以前是后台写死文案（"到点啦，今天该复盘了"），现在是**模型自己生成**：

```
触发原因：到点了，该做每日复盘了
模型生成：WH，三点啦，该复盘了。今天要捋捋不？

触发原因：内存占用已经 92%
模型生成：WH，内存快顶满了，92% 了。要我看看哪个程序在吃内存不？
```

`core/proactive_gen.py` 会把「触发原因 + 当前时间 + 用户窗口 + 最近发生的事 + 记得的事」
一起交给模型，让它用自己的语气说。模型觉得这会儿不该打扰，会回 `SKIP`，就不发。

## 已知限制

- 语音识别用的是系统自带识别器，准确率一般（安静环境 + 说清楚还行）
- 识别会等到说完或超时才返回，所以「听 5 秒」实际可能 10 秒左右
- 麦克风要能用；没麦克风会报「语音识别没起来」
