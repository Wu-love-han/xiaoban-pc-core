# 小伴控制台（人用的那个）

## 为什么单独一个程序

用户要求：**后台权限最高、AI 进不来**。

所以控制台跑在**独立进程、独立端口 8771**，和主 API（8770）完全分开。

**AI 为什么进不去**：
- AI 的工具集里没有 HTTP 客户端（`pc.shell` 白名单只有只读命令，不含 curl）
- 控制台需要 **PIN 登录**，PIN 只写在 config.json，AI 拿不到
- 即使 AI 用 `pc.open_app` 打开这个网页，它也读不到页面内容、点不了按钮

## 怎么进

| 设备 | 地址 |
|---|---|
| 电脑 | `http://127.0.0.1:8771` |
| 手机（同 WiFi） | `http://172.30.0.217:8771` |
| 手机（异地） | `http://100.118.110.25:8771` |

**PIN：556378**（在 `config.json` 的 `server.console_pin`）

## 五个页签

### 概览
- **待确认**（最上面，黄框）：AI 要改底线文件、要删东西，等你点同意/拒绝
- **三端状态**：
  - 电脑：当前焦点窗口是什么
  - 手机：在线/离线、当前前台应用、有没有 shell 权限
  - 机器人：在线/离线
- 最近会话

### 任务
- 列出所有会话
- **「中断这个」** 按钮：随时掐掉正在跑的任务

### 记忆
- 列出全部记忆（按重要度排序）
- 搜索
- **改** / **删** 每一条

### 人格
- 直接编辑 `docs/PERSONA.md`
- 保存自动备份旧版，下一轮立刻生效

### 对话
- **你和 PC 端小伴的直接对话通道**
- 它有事（比如"这条危险指令真是你发的吗"）也会在这里问你
- 控制台对话有独立会话，不跟手机/网页的聊天混

## 通知

三种情况会通知你：

| 情况 | 电脑 | 手机 |
|---|---|---|
| 主动消息（提醒、资源告急） | Windows 通知 | App 里弹气泡 |
| **等你确认**（底线操作） | Windows 通知 | App 里弹**橙色告警** |
| 任务完成 | Windows 通知 | App 里弹气泡 |

## 端口一览

```
8770  主 API + 聊天界面（AI 用）
8771  控制台（人用，PIN 保护）
9123  手机 App 本地能力服务（PC 用）
```
